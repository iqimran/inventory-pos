# Module 08 — Barcode & Printing

## Barcode
Support product barcode values.
Recommended default: Code 128 for internal product labels.

## Barcode label
Printable label should support:
- product name
- barcode graphic
- barcode number
- sale price
- optional SKU

## Printing
Provide:
- single product label,
- bulk label quantity,
- printable page,
- POS/customer sale slip,
- service invoice.

Keep print templates separate from business logic.

## Acceptance criteria
- Product barcode can be scanned into POS.
- Barcode label preview works.
- Bulk printing works.
- Sale/service documents print cleanly.
