## Implement

Create:

`docker-compose.prod.yml`

for production deployment to a VPS/cloud server.

Services:

- PHP-FPM/application
- Nginx
- MySQL
- Queue worker if required
- Scheduler if required

Requirements:

1. Use persistent volumes for MySQL.
2. Persist required Laravel storage.
3. Use environment variables for production secrets.
4. Do not commit production credentials.
5. Disable Laravel debug mode in production.
6. Configure Nginx for production.
7. PHP-FPM and Nginx must communicate through the internal Docker network.
8. MySQL must NOT be publicly exposed.
9. Configure appropriate restart policies.
10. Add health checks where useful.
11. Document:
    - server prerequisites
    - `.env` configuration
    - Docker build
    - Docker startup
    - migration
    - storage link
    - cache/config optimization
    - queue worker
    - scheduler
    - logs
    - restart
    - rollback
12. Keep the deployment simple enough for a single VPS.
13. Do not introduce Kubernetes.

## Acceptance criteria

- Production Compose configuration validates.
- Production images build.
- Containers start.
- Laravel connects to MySQL.
- migrations succeed.
- Nginx serves Laravel.
- persistent database works.
- queue/scheduler work if implemented.

## Testing

Test the production Compose configuration in a local/staging environment before production deployment.
