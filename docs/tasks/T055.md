## Implement

Establish a clean Git workflow for development, release and deployment.

## Conventional Commits

Use:

- feat
- fix
- refactor
- test
- docs
- chore
- perf
- style

Examples:

feat: implement product management

fix: prevent negative stock

refactor: extract stock movement service

test: add purchase transaction tests

docs: update deployment guide

chore: configure docker environment

## Requirements

1. Ensure `.gitignore` protects:
   - `.env`
   - credentials
   - private keys
   - generated/local files
   - sensitive database dumps

2. Never commit secrets.

3. Do not rewrite shared Git history.

4. Recommended branches:

main
→ production

develop
→ development/integration

feature/*
→ feature development

5. Recommended feature branch examples:

feature/product-management

feature/mobile-service

feature/pos-sales

fix/negative-stock

6. Document release tags such as:

v1.0.0

7. Document how Git commits, release tags and deployments relate.

8. Do not introduce unnecessary CI/CD complexity.
