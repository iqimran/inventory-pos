## Implement

Create a Docker development environment using Docker Compose.

Services:

- Laravel/PHP-FPM application
- Nginx
- MySQL

Requirements:

1. Use a persistent named Docker volume for MySQL.
2. Do NOT put MySQL inside the PHP/application image.
3. Create/update `.dockerignore`.
4. Create/update `.env.example` with Docker-compatible database configuration.
5. Configure required PHP extensions.
6. Configure Composer dependencies.
7. Configure Node/pnpm for the frontend.
8. Configure Nginx → PHP-FPM.
9. Ensure Laravel storage/cache directories are writable.
10. MySQL must not be publicly exposed.
11. Document:
    - build
    - start
    - stop
    - restart
    - logs
    - shell access
    - migration
    - seeding
    - storage link
12. Do not introduce Kubernetes or unnecessary infrastructure.

## Acceptance criteria

- `docker compose build` succeeds.
- `docker compose up -d` succeeds.
- Laravel connects to MySQL.
- migrations work.
- application is reachable through Nginx.
- frontend build/development workflow works.
- MySQL data survives container recreation.

## Testing
